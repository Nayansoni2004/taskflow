# TaskFlow

A polished, local-first productivity workspace built with Vue 3, Vite, Pinia, and Vue Router.

## Run locally

```bash
npm install
npm run dev
```

Use `npm run build` to create a production build. Application data is stored locally in the browser and can be exported or imported from Settings.

## Shortcuts

- `N` — create a task
- `/` — focus global search
- `?` — show keyboard shortcuts
- `Esc` — close the active dialog
